# Difficulty Curve

这份文档用于说明当前 20 关主线的学习目标、典型题型和难度边界。

核心原则：

- 先建立数感，再进入组合记忆
- 先加入拆分训练，再理解 `10` 的组成与超过 `10` 的数感
- `10几加几 / 10几减几` 早于 `过十加 / 退位减`
- 每关按 `热身 40% + 核心 40% + 挑战 20%` 分段抽题

## 关键分界

### 10 以上但还不算“过十策略”

- 第15关 `10几加几`：如 `10+2`、`11+3`
- 第16关 `10几减几`：如 `12-2`、`13-3`

这两关主要是让孩子习惯 “10几” 这个数感，不要求使用明显的拆分或桥接策略。

### 真正的过十 / 退位策略

- 第17关 `20 以内过十加`：如 `5+6`、`8+4`
- 第18关 `20 以内退位减`：如 `13-5`、`14-6`

这两关才正式进入“凑十”“桥接十”“退位”。
