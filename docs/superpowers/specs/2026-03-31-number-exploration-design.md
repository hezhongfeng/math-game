# 数字探索 - 可视化功能设计

> 注意：本文档描述的是 2026-03-31 的初版设计思路，当前实现已明显演进。
> 最新实现包括自由探索、可选范围挑战、Three.js 3D 球阵、移动端自动旋转，以及按十/百分组的视觉层次。

## 概述

为儿童设计一个数字与物体数量对应关系的探索功能。孩子可以通过输入数字（1~1000），直观看到对应数量的小球阵列展示，帮助理解十进制概念。

## 功能入口

在 Home 页面添加新的「数字探索」卡片入口：
- 图标：`🎱` 或 `🔢`
- 文字：叫"数字探索"或"小球的秘密"
- 样式：与其他难度卡片保持一致

## 当前实现补充

- 页面已从“输入视图 / 展示视图”扩展为：
  - 自由探索：输入数字后查看球阵，并可继续浏览相邻数量
  - 挑战模式：手动选择训练范围，在固定范围内持续猜数练习
- 小球展示不再区分 rows/flats/cube 三套独立 UI，而是统一为 Three.js 3D 十进制球阵
- 挑战范围已拆分为从 `10以内` 到 `751-1000` 的渐进区间，支持持续刷同一档

## 页面设计

### 两种视图状态

#### 视图一：输入视图
- 数字键盘（可复用现有的 NumberPad 组件）
- 输入显示区域（显示当前输入的数字）
- 确认按钮

#### 视图二：展示视图
- 小球阵列可视化区域
- 文字说明（"4行 + 7个 = 47"）
- 返回按钮（重新输入）

### 视图切换
- 同一页面切换，点击确认后隐藏输入区、显示展示区
- 非跳转，是同一页面的两种状态切换

## 小球展示规则

严格十进制展示：

| 输入 | 展示 |
|------|------|
| 13 | 1行 + 3个 = 13 |
| 47 | 4行 + 7个 = 47 |
| 100 | 10×10 的一面 = 100 |
| 150 | 1面 + 50个 = 150 |
| 250 | 2面 + 50个 = 250 |
| 1000 | 10×10×10 立方体 = 1000 |

### 展示示例

```
输入 47：
┌─────────────┐
│ ●●●●●●●●●●● │ 第1行 (10)
│ ●●●●●●●●●●● │ 第2行 (10)
│ ●●●●●●●●●●● │ 第3行 (10)
│ ●●●●●●●●●●● │ 第4行 (10)
│ ●●●●●●      │ 第5行 (7)
└─────────────┘
显示文字："4行 + 7个 = 47"
```

```
输入 150：
┌─────────────┐  ┌─────────────┐
│ ●●●●●●●●●●● │  │ ●●●●●●...   │  (展示2面)
└─────────────┘  └─────────────┘
显示文字："1面(100个) + 5行(50个) = 150"
```

## 交互流程

1. 孩子在输入视图点击数字按钮输入（如输入 47）
2. 显示当前输入数字 "47"
3. 点击「确认」按钮
4. 视图切换到展示视图
5. 小球动画逐行/逐面出现
6. 显示底部文字说明

## 视觉设计

### 小球样式
- **形状**：圆形，带立体光照效果
- **颜色**：蓝色系（hero-blue 主题色）
- **效果**：
  - 径向渐变模拟光照（高光在左上角）
  - 轻微投影增加立体感
- **大小**：
  - 数量少时（<100）可显示较大
  - 数量多时自动缩小以适应屏幕

### 动画效果
- 小球出现时有轻微弹跳动画
- 逐行/逐面依次出现（可选，时长约1-2秒）

## 边界处理

- 输入 0 → 提示"请输入大于0的数字"
- 输入 >1000 → 提示"最大支持1000个哦"
- 空输入 → 提示"请输入数字"

## 技术实现要点

1. 可复用现有的 NumberPad 组件
2. 计算小球行列使用严格十进制逻辑
3. 需要写一个新的展示组件 `BallArray.vue`
4. 使用 CSS 径向渐变实现小球立体效果
