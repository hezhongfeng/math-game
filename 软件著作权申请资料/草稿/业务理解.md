# 业务理解

- 软件名称：数学运算游戏软件
- 产品定位：一款面向学龄前及小学低年级儿童的移动优先数学启蒙训练软件，围绕加减法闯关、数量感培养和即时反馈练习，帮助儿童在游戏化操作中完成基础运算训练。
- 面向领域 / 行业：儿童教育软件 / 数学启蒙训练
- 核心价值：通过分阶段闯关、及时反馈、错题复练和数字可视化探索，把抽象的加减法练习转换成适合儿童持续参与的交互体验，帮助用户逐步建立数感、运算熟练度和学习成就感。
- 证据文件：`业务理解证据.md`

## 目标用户

- 学龄前儿童和小学低年级学生
- 需要进行基础加减法启蒙训练的家庭用户
- 用于课后巩固和课堂辅助练习的教师或培训机构

## 主要业务功能

- 渐进式关卡训练
- 即时反馈与闯关机制
- 错题复练与成绩追踪
- 数字探索与数量感训练
- 移动端离线学习支持

## 功能说明

- 渐进式关卡训练：软件内置 26 个主线关卡，按 0-3、5 以内、10 以内、20 以内等学习阶段逐步扩展题目范围、题型结构和题量，用户需按顺序通过关卡，形成循序渐进的训练路径。
- 即时反馈与闯关机制：用户在练习页通过数字键盘输入答案，答对后自动切换下一题，答错时停留当前反馈界面并展示正确答案，整关完成后按正确率判断是否通过，并在通过后解锁下一关。
- 错题复练与成绩追踪：软件记录每一轮答题结果、错题列表、最佳成绩和本地计时榜，用户可以在结算页查看错题并仅针对错误题目重新开始一轮训练，同时避免把复练成绩混入正式闯关榜单。
- 数字探索与数量感训练：除主线练习外，软件提供 1-1000 的数字探索功能，支持自由输入数字查看十进制球阵，也支持按区间进行猜数挑战，帮助儿童理解数字与数量之间的对应关系。
- 移动端离线学习支持：软件采用移动优先界面设计，适配竖屏触控操作，支持本地存储学习进度与成绩，并通过 PWA 能力提供安装、缓存和更新提示，方便在网络条件一般的场景下继续使用。

## 典型操作流程

1. 用户打开软件后进入首页，可选择开始主线挑战或进入数字探索。
2. 选择主线挑战时，用户进入关卡选择页，查看已通关进度、已解锁关卡和各关成绩信息。
3. 用户进入具体关卡后，通过数字键盘逐题作答，系统根据答案给出正确或错误反馈，并在答对时自动推进。
4. 完成当前关卡全部题目后，系统展示正确率、用时、星级、榜单信息和错题情况，用户可重新开始或仅重练错题。
5. 选择数字探索时，用户可在自由探索模式输入 1-1000 的数字查看球阵，也可切换到挑战模式进行区间猜数训练。

## 操作手册页面/流程模块

1. 首页入口：用户打开软件后默认进入“/”首页。
   - 使用场景：用户首次打开软件或完成其他页面操作后，会回到首页决定是继续闯关训练还是进入数量探索。
   - 操作要点：打开软件后查看首页显示的标题、引导语和当前学习数据。；点击“开始挑战”进入关卡选择页。；点击“数字探索”进入数量探索页面。；如已有学习记录，可先查看已通关和累计答对情况，再决定下一步操作。
2. 关卡选择页面：用户从首页点击“开始挑战”进入“/difficulty”页面。
   - 使用场景：用户进入主线训练后，需要先在该页面查看当前可玩的关卡，并根据解锁顺序选择目标关卡。
   - 操作要点：进入页面后先查看页首显示的已通关进度和进度条。；向下浏览各阶段的关卡卡片，找到已解锁的目标关卡。；点击可用关卡卡片进入对应练习页面。；如需返回首页，可点击左上角返回按钮。
3. 关卡练习与作答：用户在关卡选择页点击某一关卡后进入“/game/:id”页面。
   - 使用场景：用户进入任一已解锁关卡后，在该页面逐题完成加减法练习，并根据反馈继续作答直至完成整关。
   - 操作要点：查看当前题目的算式、题号和作答区域。；通过数字键盘输入答案，必要时可使用删除键修改输入内容。；点击确认键提交当前答案。；如果答对，等待系统自动切换到下一题。
4. 结算结果与错题重练：用户在练习页完成当前关卡全部题目后自动弹出结算结果界面。
   - 使用场景：用户完成一关全部题目后，需要在该页面查看自己的正确率、用时和错题情况，并决定是否重新挑战或重练错题。
   - 操作要点：完成整关后查看结算面板中的正确率、用时和通过情况。；查看是否刷新最佳成绩或进入计时榜。；如需重新完整训练，点击重新开始按钮。；如需集中练习错误题目，点击仅重练错题按钮。
5. 数字探索-自由探索：用户从首页点击“数字探索”进入探索页，默认处于自由探索模式。
   - 使用场景：当用户希望脱离关卡训练，以更直观的方式观察数字与数量关系时，会使用自由探索模式。
   - 操作要点：进入页面后保持在自由探索模式。；通过数字键盘输入 1 到 1000 之间的数字，或直接点击快捷数量按钮。；点击确认后查看对应数量的小球阵列和数字构成说明。；如需继续观察相邻数量，可在结果页继续调整当前数字。
6. 数字探索-挑战模式：用户在数字探索页点击“挑战模式”切换按钮进入挑战模式。
   - 使用场景：当用户已经具备一定数字基础，希望通过球阵先观察、再输入猜测值的方式加强数量感时，会使用挑战模式。
   - 操作要点：切换到挑战模式后查看当前挑战区间和提示语。；先观察当前题目的球阵或挑战提示，再输入自己的猜测数字。；点击确认提交猜测结果。；查看系统公布的正确答案以及本次是否猜中的反馈。

## 申请表建议口径

- 开发目的：用于帮助儿童开展循序渐进的基础加减法启蒙训练和数量感培养。
- 软件的主要功能：软件提供首页入口、关卡选择、闯关练习、结果结算、错题重练和数字探索等核心功能。首页展示训练入口与探索入口，并显示已通关数量和累计答对题数。关卡选择模块按阶段展示 26 个主线关卡，提供解锁状态、最佳成绩和同题量计时榜信息。练习模块根据关卡配置自动生成适龄题目，支持加法、减法、综合题和缺项题，用户可通过大尺寸数字键盘输入答案，系统在作答后即时给出正确或错误反馈。结算模块根据正确率判断是否通过，展示星级、用时、新纪录和错题列表，并支持重新开始或只针对错题重新训练。数字探索模块支持输入 1-1000 的数字查看对应的三维十进制球阵，也支持按范围进行挑战练习，帮助用户理解数字构成和数量关系。软件还提供本地学习进度保存、榜单过滤、小球辅助、音效与振动反馈、PWA 安装与离线缓存等配套能力。
- 技术特点：软件采用 Vue 3 与 Vite 构建前端单页应用，通过配置化关卡规则和题目生成算法实现分阶段出题，使用 LocalStorage 持久化学习进度、成绩榜单与偏好设置，使用 Three.js 展示 1-1000 的十进制球阵，并结合 Web Audio API、触觉反馈和 PWA 缓存机制提升移动端学习体验。
- 软件的技术特点选项：教育软件、游戏软件
- 软件分类：应用软件
