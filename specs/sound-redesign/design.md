### 音效类型设计

#### 1. 点击音效 (Click Sounds)
- **数字键 (0-9)**: 每个数字有独特的轻微音高变化，使用 FM 合成创造"数字感"
- **删除键**: 短促的下滑音，使用波表合成
- **提交键**: 双音上扬，使用加法合成
- **通用点击**: 极短瞬态音，使用噪声振荡器

#### 2. 反馈音效 (Feedback Sounds)
- **正确反馈**: 五度上扬音阶，使用和弦合成
- **错误反馈**: 短促下降音，使用带滤波器的脉冲波
- **胜利音效**: 根据星星数量的递增音阶，使用多振荡器合成

#### 3. 界面音效 (UI Sounds)
- **页面切换**: 轻微的空间混响效果
- **按钮悬停**: 极短促的频闪效果
- **加载完成**: 扫频上升音

### 技术栈选择

#### 音频合成技术
1. **FM 合成 (Frequency Modulation)**: 用于数字键音效，创造电子感
2. **波表合成 (Wavetable)**: 用于删除键音效，创造平滑变化
3. **加法合成 (Additive)**: 用于提交键音效，创造丰富谐波
4. **减法合成 (Subtractive)**: 用于正确反馈音效，过滤多余频率

#### 音频效果
1. **低通滤波器**: 削减刺耳高频
2. **压缩器**: 平衡音量，避免爆音
3. **卷积混响**: 添加空间感
4. **延迟效果**: 创造回声效果
5. **包络发生器**: 控制音色变化

### 音效参数设计

#### 频率设计
```javascript
// 现代科技风格音阶 (基于 C 大调)
const TECH_SCALE = {
  // 数字键: 每个数字对应不同音高
  digits: [261.63, 293.66, 329.63, 349.23, 392.00, 
           440.00, 493.88, 523.25, 587.33, 659.25], // C4-D5
  
  // 正确音效: 上扬和弦 (C-E-G)
  correct: [523.25, 659.25, 783.99, 1046.50], // C5-E5-G5-C6
  
  // 错误音效: 下降小三度
  wrong: { start: 440.00, end: 349.23 }, // A4-F4
  
  // 胜利音效: 根据星星数量递增
  win: {
    1: [523.25], // C5
    2: [523.25, 659.25], // C5-E5
    3: [523.25, 659.25, 783.99], // C5-E5-G5
    4: [523.25, 659.25, 783.99, 1046.50], // C5-E5-G5-C6
    5: [523.25, 659.25, 783.99, 1046.50, 1318.51] // C5-E5-G5-C6-E6
  }
}
```

### 性能优化策略

#### 1. 音频缓存
- 预先生成常用音效的 AudioBuffer
- 使用对象池管理 AudioNode
- 延迟初始化不常用的音效

#### 2. 限流机制
```javascript
const COOLDOWN_MS = {
  click: 25,      // 点击音效冷却
  feedback: 80,   // 反馈音效冷却
  win: 200        // 胜利音效冷却
}
```

#### 3. 移动端优化
- 按需初始化 AudioContext
- 处理 iOS Safari 的自动暂停
- 处理微信浏览器的特殊限制
- 后台时降低音频质量

#### 4. 内存管理
- 及时释放不再使用的 AudioNode
- 限制同时播放的音效数量
- 使用 Web Workers 处理复杂合成

### 兼容性处理

#### iOS Safari
1. **自动暂停**: 监听页面可见性变化
2. **用户交互**: 必须在用户交互后恢复 AudioContext
3. **音频解锁**: 需要播放一个无声音频

#### 微信浏览器
1. **特殊限制**: 需要特殊音频解锁机制
2. **自动播放**: 更严格的自动播放策略
3. **音频上下文**: 需要额外的恢复逻辑

#### Android Chrome
1. **低延迟**: 使用最佳音频参数
2. **性能优化**: 避免过度音频处理
3. **内存管理**: 及时清理音频资源
